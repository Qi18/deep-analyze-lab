# 项目说明

DeepAnalyze Lab 是一个面向应用算法岗和 Agent 算法岗的自主数据分析 Agent 学习与实验项目。它不是重新实现 DeepAnalyze，而是在固定上游基线的基础上，完成部署复现、执行反馈研究、统一评测、课程式后训练和效果分析。

## 要解决的问题

系统接收表格或文件型数据分析任务，由模型生成分析与 Python 代码，执行代码后读取环境反馈，继续修正或生成带图表的报告。本项目关注三个问题：

1. 工具执行给基础模型带来多少真实收益。
2. SFT、Cold Start 和 GRPO 分别改变哪些能力。
3. 如何用独立测试集、失败样本和成本指标证明改进，而不是只展示成功案例。

## 范围边界

- `DeepAnalyze/` 是固定上游源码，能力归属必须明确。
- `labs/` 保存各阶段学习过程、实验配置和可验证结论。
- `src/` 只保存本项目形成且跨阶段复用的实现。
- 模型权重、完整数据和原始日志不进入 Git。
- 未在独立评测中验证的训练或提升，不写入简历成果。

当前 Phase 1 已证明官方模型能够在 L20 上完成文件分析和多轮执行，也暴露了月份排序错误和答案解释不一致；这些问题将转化为后续评测断言与改进目标。
